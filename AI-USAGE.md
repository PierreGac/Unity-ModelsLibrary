# AI usage

Models Library is written and maintained by Pierre Gac. The first versions were written by hand. Later work used AI coding assistants for organization, Editor async flows, tests, and documentation. Product decisions and review stay with the author.

## Tools

AI coding assistants were used while editing this repository. They are development tools. They are not included in the package, and this disclosure does not depend on one vendor.

The package also ships optional Unity Assistant skill files. They stay unused until you set them to Allow under **Edit > Preferences > AI > Skills** (macOS: **Unity > Settings > AI > Skills**). After that, they run in Unity Assistant, not as code in this package.

## Affected content

Assistants have helped revise Editor code, tests, and the package documents, including this file. The Example sample is an original cube and repository written for this package.

## Human review

The author reviews assistant output before it is kept. Generated text is not published as-is.

## Data handling

What you type into an assistant, and any repository context that assistant sends, is handled under that product's own terms. This package does not contain an AI model. At Editor runtime it does not send the catalog, repository files, or project assets to an AI service.

## What the package does not do

It does not generate meshes, call a model API, or make runtime decisions with AI. The only AI-related files a user receives are the optional Assistant skills.
